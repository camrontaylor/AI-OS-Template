# Editing generated slides with Canva Magic Layers

Use this guide to make small changes to an exported slide without generating it again.

1. Download the slide's PNG from its local preview.
2. Open Canva and find Magic Layers using its search or home-screen shortcuts.
3. Upload one slide at a time and let Canva process it into editable elements.
4. Open Position, then Layers, to select individual text, shapes, and backgrounds.
5. Make your edits and use Share, then Download, to export a PNG.

For text, select the text layer to change the copy, font, size, or color. Select an object layer to change its color or position. Reorder layers when text sits behind a shape. If Canva substitutes a font, reapply your brand font.

Clean template layouts with distinct text zones usually separate well. A composited photograph or generated scene may remain a single image layer. Complex textures may merge or lose quality; regenerate the slide when editing the extracted layers does not produce a clean result.

Use layer editing for a typo, a color change, a font adjustment, or minor repositioning. Use the original generation workflow for a new hook, a different concept, or a full redesign.
