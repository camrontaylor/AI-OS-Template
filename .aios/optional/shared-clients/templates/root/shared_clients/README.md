# Shared Clients

This optional folder is for client collaboration that the team has explicitly
decided to share.

It is not the same as `clients/`. The normal `clients/` folder remains private
by default and is stripped from clean team system exports.

Before using this folder for real client work, define:

- who can read it
- who can edit it
- what client data is safe to version
- what stays private in each teammate's local `clients/` workspace
- how conflicts and handoffs are handled
