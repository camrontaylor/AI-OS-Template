# Team Context

This folder is optional shared knowledge for the team.

It is not personal memory. Keep private notes in `context/`, client work in
`clients/`, and raw captures in `team_context/inbox/` until they are reviewed.

Use this folder for:

- shared decisions
- reusable operating notes
- source summaries
- team-wide methods that should survive across sessions

Do not store secrets, API keys, private client details, or unreviewed personal
memory here.
