# Security

Do not publish credentials, private client files or exploit details in a public issue.
For a sensitive report, contact the maintainer through the GitHub profile and agree
on a private reporting channel before sharing details.

Keep the local dashboard on your computer or a deliberately configured private
network. Use your own agent's trust and permission controls. Keep working repositories
private and keys in local ignored configuration. Follow the actual provider and
connector access settings; a local folder does not make cloud calls offline.
