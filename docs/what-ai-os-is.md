# What AI-OS is

AI-OS gives your AI assistant a workspace for your business context, saved decisions,
repeatable methods and finished work. It is a folder of normal files around your chosen agent.

Your profile tells the agent how you like to work. Brand files describe your audience,
offer and voice. Skills give it a method. Memory notes preserve useful decisions and
unfinished work. Project folders keep results from getting lost in a chat.

Ask for a proposal, research summary, campaign, client deliverable or code change.
The agent loads the relevant files, uses a suitable method, checks the result and saves it.
You review the output and correct what needs changing.

Codex and Claude Code have shared instructions and skill discovery in this release.
Other agents can read the files, but their integrations and discovery differ.
The optional Command Centre provides a browser interface; it is not required for direct agent work.
