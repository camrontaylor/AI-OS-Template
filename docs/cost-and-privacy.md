# Cost and privacy

AI-OS is local-first, not offline-only. Your workspace files live on your machine
unless you push, sync, upload or connect them elsewhere.

Your agent may send prompts and selected file content to its model provider.
Connected apps can read or write service data; enabled logging, hosting and backups
have their own destinations. Local scheduling can still make paid external calls.

Costs come from your chosen AI tool, model/API usage, connected services, scheduled
jobs and optional hosting. The template itself does not provide a shared account or usage allowance.

Keep keys in local `.env` files. Use a private repository for business context,
memory and deliverables. Connect only what you need; ask about cost before heavy work.
Client folders guide which context the agent loads, but folder separation alone
is not security isolation against a tool with broad filesystem permissions.

The public template begins with blank profiles, empty working memory and paused
example jobs. Your own work changes those files in your copy.
